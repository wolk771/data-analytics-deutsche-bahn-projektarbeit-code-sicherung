# data-analytics-deutsche-bahn-projektarbeit-code-sicherung

Sicherung des Abschlussprojektes aus dem Kurs Data Analytics.

Für Ausführen der einzelnen Jupyter Notebooks ist Datensatz aus der Beschreibung (Projektvorschlag) sowie Registrierung für die Nutzung von DB-APIs erforderlich.

Aus der 'project_config.py' ist ebenfalls ersichtlich, wo die Datei innerhalb des Projektverzeichnisses abzulegen sei sowie wo folgende Dateien erstellt werden.

Ausgeführte Notebooks werden hier in der HTML- und PDF-Format dargestellt.

Haupt Notebook ist 'Projekt_DeutscheBahn.ipynb' Datei. Alle "Hilfe-Notebooks" sind nummeriert. Create_Documents.ipynb ist nur für die Erstellung von HTML- und PDF-Dokumenten von ausgeführten Notebooks verantwortlich.
